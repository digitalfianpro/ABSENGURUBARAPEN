Panduan Penggunaan Aplikasi Presensi

1. Pengisian & Import Data Guru

Klik tombol "Unduh Template Excel" pada menu Data Guru. Isi data NIP, Nama, Jabatan, dan Nomor WA. Setelah itu klik "Upload Excel Guru" untuk memasukkan seluruh data secara otomatis.

2. Upload Foto Massal Berdasarkan NIP

Beri nama file foto guru sesuai NIP masing-masing (contoh: 198503122010011005.jpg). Gunakan tombol "Upload Foto (Nama File=NIP)" untuk mencocokkan foto ke guru yang sesuai sekaligus secara instan.

3. Proses Scan Barcode Presensi

Gunakan Kamera HP/Laptop atau Scanner USB Barcode. Ketika NIP terdeteksi, foto guru akan muncul dalam ukuran besar beserta jam presensi WIT, lalu notifikasi WhatsApp dikirimkan.

4. Rekapan Perbulan & Perminggu

Pilih mode "Rekapan Bulanan" atau "Rekapan Mingguan" pada menu Rekapan. Hari Minggu otomatis ditandai merah beserta perhitungan % Kehadiran. Klik "Download Excel Resmi" untuk mengunduh laporan berformat matriks yang rapi.
