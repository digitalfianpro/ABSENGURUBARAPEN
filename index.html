Panduan Penggunaan Aplikasi Presensi

1. Cara Scan Presensi Guru

• Kamera Web: Klik tombol "Aktifkan Kamera Scanner" di tab Scan Hari Ini lalu arahkan QR Code pada kartu guru ke kamera.

• Alat Scanner USB Barcode: Pilih mode "USB Barcode", klik kolom input NIP, lalu gunakan scanner gun hardware.

• Presensi otomatis tersimpan realtime dan mengirim notifikasi WhatsApp ke Guru & Kepsek jika WA Gateway dikonfigurasi.

2. Upload Data Guru via Excel

• Masuk ke menu Master Data Guru, klik tombol "Upload Excel Data Guru".

• Buat file Excel dengan header kolom di baris pertama: NIP, Nama, Jabatan, WA.

• Sistem akan otomatis membaca dan mendaftarkan semua baris data guru ke dalam aplikasi secara instan.

3. Upload Foto Massal Berdasarkan NIP

• Siapkan file-file foto guru yang sudah diberi nama sesuai NIP masing-masing. Contoh file: 19850312.jpg atau 19900415.png.

• Klik tombol "Upload Foto (Sesuai NIP)" dan pilih banyak foto sekaligus. Foto akan langsung tercocokkan dengan NIP guru secara otomatis.

4. Rekapan Perbulan & Perminggu (Fitur Terbaru)

• Rekapan Perbulan: Menampilkan tabel matriks dari tanggal 1 hingga akhir bulan. Kolom Hari Minggu berwarna MERAH.

• Rekapan Perminggu: Menampilkan 7 hari kerja (Senin s/d Minggu) dengan penandaan tanggal presisi dan statistik persen (%).

• Klik tombol "Download Excel Rekapan" untuk mendapatkan berkas laporan Excel format resmi sekolah.
