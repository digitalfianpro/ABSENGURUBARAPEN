Panduan Penggunaan Aplikasi Presensi

Mode Scan QR Code / NIP Manual

Pilih opsi Kamera untuk menggunakan webcam HP/Laptop, atau Scanner USB jika menggunakan alat barcode scanner eksternal. Profil guru beserta foto ukuran besar akan muncul otomatis.

Menambah Data & Export Template Excel

Anda dapat mendownload Template Excel pada tab Data Guru, mengisi data NIP dan Nama, lalu mengupload kembali secara langsung via tombol Upload Excel Guru.

Upload Foto Massal Sesuai NIP

Namai file foto guru sesuai NIP masing-masing (contoh: 19850312.jpg). Upload banyak foto sekaligus pada tombol Upload Foto (Sesuai NIP), sistem akan menyinkronkan foto secara otomatis.

Laporan Rekapan Perminggu & Perbulan

Pilih Tipe Rekapan (Perbulan atau Perminggu) di menu Rekapan. Hari Minggu (Sunday) akan diwarnai MERAH secara otomatis. Klik tombol Download Excel Resmi untuk mengunduh laporan Excel terformat rapi.
