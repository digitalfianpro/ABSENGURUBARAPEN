Panduan Penggunaan Sistem Presensi

1 Melakukan Scan Presensi Guru

  • Kamera HP/Webcam: Tekan tombol "Aktifkan Kamera" lalu arahkan Kartu QR NIP guru ke depan kamera.
  • Barcode Hardware USB: Ganti mode ke "USB", arahkan pemindai ke Kartu QR guru. Data NIP akan terinput secara otomatis.
  • Input Manual: Masukkan NIP pada kolom input manual dan tekan Enter / tombol "Proses".

2 Manajemen Guru & Upload Foto Massal

  • Buka menu "Master Data Guru" untuk melihat, menambah, mengedit, atau menghapus data guru.
  • Cetak QR Code: Klik tombol "Kartu QR" pada profil guru untuk mencetak kartu ID presensi.
  • Upload Foto Massal: Siapkan file foto dengan nama file sesuai NIP Guru (contoh: 198503122010011005.jpg). Pilih banyak foto sekaligus dengan tombol "Upload Foto (Nama = NIP)". Foto akan otomatis tersinkronisasi ke profil guru masing-masing.

3 Laporan Rekapan Perminggu & Perbulan

  • Rekapan Perbulan (Kalender Matriks): Menampilkan matriks kehadiran tanggal 1 sampai akhir bulan. Hari Minggu ditandai dengan warna MERAH secara otomatis. Lengkap dengan persentase kehadiran tiap guru.
  • Rekapan Perminggu (7 Hari Full): Menampilkan matriks hari Senin s/d Minggu lengkap dengan detail jam dan tanggal.
  • Export File: Tekan "Download Excel" untuk mengunduh laporan presensi resmi.

4 Notifikasi WhatsApp Gateway Automatis

Buka "Pengaturan Sistem", masukkan API Key (Fonnte API Token) dan Nomor WA Kepala Sekolah. Notifikasi WhatsApp akan otomatis dikirim ke Guru & Kepsek saat guru berhasil presensi!
