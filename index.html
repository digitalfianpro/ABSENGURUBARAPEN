Panduan Penggunaan Aplikasi

1. Presensi Scan QR / Barcode Hardware

• Klik menu Scan Hari Ini.
• Pilih mode Kamera untuk scan QR Code dari HP/Kartu, atau pilih mode USB jika menggunakan barcode scanner kabel standar.
• Jika NIP terdaftar, data presensi langsung tersimpan dan otomatis mengirim notifikasi WhatsApp.

2. Upload Data Guru via Excel

• Buka tab Data Guru & klik tombol Upload Excel Data Guru.
• Pilih file `.xlsx` atau `.csv`. Pastikan header kolom memiliki judul NIP, Nama, Jabatan, dan WA.
• Data akan diimpor dan disimpan otomatis secara permanen.

3. Upload Foto Massal Berdasarkan NIP

• Siapkan file foto guru dengan nama file sesuai NIP (misal: 198503122010011005.jpg).
• Klik tombol Upload Foto Batch dan pilih banyak file foto sekaligus.
• Sistem akan menyinkronkan foto ke profil guru yang cocok.

4. Laporan Perbulan (1-31) & Perminggu (7 Hari)

• Buka tab Rekapan & Excel.
• Pilih Tipe Rekapan Perbulan untuk melihat tabel kalender tanggal 1 sampai 31 dengan highlight merah pada hari Minggu.
• Pilih Tipe Perminggu untuk melihat matriks 7 hari (Senin - Minggu).
• Klik Download Excel untuk mengunduh laporan rapi ke komputer.
